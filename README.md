# Subtitle to Text

A free, fast, no-signup, 100% client-side web application that converts `.srt` and `.vtt` subtitle files into clean, readable transcripts.

**Live Application:** [https://bangsuhyoek.github.io/subtitle-to-text/](https://bangsuhyoek.github.io/subtitle-to-text/)

## Features

- **Zero Setup &amp; No Signup**: Free and instant without accounts, paywalls, or limits.
- **100% Client-Side Privacy**: All processing runs in your browser via Web APIs. Subtitle files never leave your computer.
- **Universal Formats**: Supports SubRip (`.srt`) and WebVTT (`.vtt`), auto-detecting timestamps, BOM, CRLF, and metadata headers.
- **Cleans Annoying Formatting**: Automatically strips cue numbers, millisecond timestamps, HTML/inline styling (`<i>`, `<b>`, `<c.color>`, SubStation `{\an8}`), and HTML entities.
- **YouTube Deduplication**: Removes overlapping rolling captions generated by YouTube auto-captions.
- **Flexible Paragraphs**: Groups dialogues into coherent paragraphs by natural time pauses (e.g., &gt;2s pause) or sentence boundaries.
- **Speaker Preservation**: Preserves speaker names from WebVTT `<v Speaker>` cues as `Speaker: dialogue`.
- **Sound Tags Filter**: Optional toggle to remove sound cues like `[Music]`, `(applause)`, `[Laughter]`, `♪`.
- **Multiple File Support**: Drag & drop multiple files, preview each file via tabs, and download individually or combined.
