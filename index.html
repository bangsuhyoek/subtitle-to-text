How it works

1. Drag any .srt or .vtt subtitle file into the editor, or paste raw caption text.

2. Timestamps, cue markers, HTML tags, and YouTube rolling duplications are removed instantly.

3. Text is grouped into paragraphs by natural speaker pauses, ready to copy or download as clean prose.

Frequently asked questions

How are timestamps and numbers removed?

The parser matches standard subtitle cue blocks, strips numeric counters and millisecond timing markers (such as 00:01:23,456 --> 00:01:25,789), and extracts only dialogue text.

How does it handle WebVTT tags and styling?

WebVTT headers, NOTE comments, STYLE blocks, and cue positioning metadata are skipped. Inline voice tags (<v Name>) are converted into clean speaker prefixes, and sound annotations like [Music] can be stripped automatically.

What causes YouTube auto-captions to repeat words?

YouTube auto-captions generate rolling teleprompter cues where each cue repeats the previous cue's second line. Subtitle to Text detects overlapping rolling suffixes and merges them into a single clean sentence without repeated phrases.

Do files ever leave my computer?

No. Processing runs entirely in your local browser using client-side JavaScript. No audio, subtitles, or transcripts are uploaded to any server or remote service.
